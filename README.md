# Texture Pixel Editor — Forge 1.20.1

## Получение JAR без установки Gradle на компьютер

1. Войди на GitHub (если аккаунта нет, попроси взрослого помочь с регистрацией).
2. Создай репозиторий `TexturePixelEditor`.
3. Распакуй этот ZIP.
4. На странице репозитория нажми **Add file → Upload files**.
5. Загрузи ВСЕ файлы и папки из распакованного проекта. Обязательно включи скрытую папку `.github`.
6. Нажми **Commit changes**.
7. Открой **Actions**. Сборка запустится автоматически. Если нет — выбери **Build Minecraft mod** → **Run workflow**.
8. После зелёной галочки открой завершённый запуск, найди **Artifacts** и скачай `TexturePixelEditor-JAR`.
9. Распакуй скачанный архив и найди файл `.jar`.
10. Положи его в `.minecraft/mods` и запусти Forge 1.20.1.

Gradle на свой компьютер устанавливать не нужно: сборку выполнит GitHub.

## Возможности
- Загрузка ванильных текстур по пути, например `block/stone`, `item/diamond`.
- ЛКМ — закрасить пиксель выбранным цветом; ПКМ — сделать прозрачным.
- Отмена последних действий.
- Сохранение PNG в отдельный ресурс-пак `TexturePixelEditor`.
- Сброс сохранённого PNG; оригинальные файлы игры не изменяются.

## Использование
1. Запусти игру и нажми «Редактор текстур».
2. Введи путь без `textures/`, например `block/stone`, затем «Загрузить».
3. Введи цвет `#RRGGBB`, нажми «Применить цвет».
4. Рисуй по пикселям и нажми «Сохранить».
5. В Minecraft открой Настройки → Наборы ресурсов и включи `TexturePixelEditor`.

Первая версия редактирует ванильные текстуры пространства имён `minecraft`.
